Авито Дейтинг

Макеты для кейса «Между сделками» · 3 концепции, по 3 экрана

A · Мэтч по вещам B · Компания C · Внутри сделки
A

Мэтч по вещам

Свайпы как в Tinder, но анкету Авито собирает само — из истории сделок. Доверие видно сразу: рейтинг продавца и «полка» с объявлениями. Первая фраза — про конкретную вещь.

B

Компания по интересам

Вход с главной: «12 человек рядом тоже собирают винил». Дальше — встречи рядом, и рядом с каждой подсказка, что нужное для неё есть на Авито.

C

Знакомство внутри сделки

Без отдельного раздела: плашка об общих интересах прямо в объявлении, безопасная встреча в чате по вещи, настройки приватности.

Статичные макеты, данные в интерфейсе — примеры.
